# CS2 Resources
A collection of resources for **Counter-Strike 2**, organized for anyone working with CS2.

## Resources
| Directory | Description |
| --- | --- |
| [`generated_protobufs/`](./generated_protobufs/) | Generated Protocol Buffer files for CS2. (C++) |

## Getting Started
Browse the directories above, or clone the repository to access the files locally:

```bash
git clone https://github.com/pagefaultcc/cs2-resources.git
cd cs2-resources
```

## Contributing
Contributions, corrections, and additional resources are welcome. If you notice outdated files, missing information, or something worth adding, [open an issue](https://github.com/pagefaultcc/cs2-resources/issues) or submit a pull request.
